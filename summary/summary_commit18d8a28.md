# สรุป commit `18d8a28` — Add hub, final and reserve roles, and three spiral2 blueprints

- **Branch:** `ai-sim` (ต่อจาก `c7ffa6d`)
- **ที่มา:** ข้อเสนอ hub6 (ทำเฉพาะส่วนที่ไม่ต้องใช้ slate และ stun) รวมกับการปรับปรุง spiral ตามที่ขอให้ทำใน spiral2

## สิ่งที่เพิ่ม

### roles ใหม่ใน blueprint

| role | ความหมาย |
|---|---|
| `wall` | กำแพง (เดิม) |
| `slot` | จุดสำหรับ tower ที่ keep (เดิม) |
| `final` | slot บนช่วงสุดท้ายก่อนทางออก |
| `reserve` | ช่องที่ยังไม่สร้างจนถึง `unlockLevel` เป็นที่สำหรับ tower ช่วงท้าย |
| `hub` | เว้นว่างไว้ ให้ทางเดินผ่านซ้ำหลายรอบ (ไม่มี order) |

blueprint กำหนด `hub` (สี่เหลี่ยมสำหรับนับรอบ) และ `phases` (ถึงด่าน N ต้องผ่าน hub อย่างน้อย M รอบ) ได้

### บอท

- **reserve**: เข้า window ของแปลนได้ก็ต่อเมื่อถึงด่านที่ปลดล็อก
- **`reserveRespect`** (ใหม่, ค่าเริ่มต้น 0, ขอบเขต 0–20): หักคะแนน 10 × ค่านี้ เมื่อจะวางลงช่อง hub หรือ reserve ที่ยังล็อกอยู่
- **`slotKeepBonus`**: ใช้กับ slot / final / reserve

### บันทึกและรายงาน

- **`GameRecord.hubPasses`**: จำนวนรอบที่ทางพื้นผ่าน hub ตอนเริ่มแต่ละเวฟ (นับตามจำนวนครั้งที่ทางเข้าสี่เหลี่ยม hub)
- **รายงาน**: แสดงจำนวนรอบที่ผ่าน hub ตอนตาย และนับ slot ทุกแบบ

### เครื่องมือ (`npm run blueprint`)

- `render` แสดง `F` final, `R` reserve, `H` hub และจำนวนรอบที่ผ่าน hub
- `stats` แสดงจำนวนรอบที่ผ่าน hub รายด่าน
- `validate` ตรวจ role, `unlockLevel` ของ reserve และเป้าของแต่ละ phase
- จำนวนช่องในงบนับเฉพาะช่องที่สร้างจริง (ไม่นับ hub)

**หลักการของกำแพง hub:** ไม่ต้องสร้างกรวยเต็มวง แค่กำแพงเส้นเดียวต่อ checkpoint ก็พอ

- ด้านอื่นของกรวยไม่มีผล เพราะครีปไม่มีเหตุผลจะเดินไปทางนั้นอยู่แล้ว
- เป้า 6 รอบทำไม่ได้บนแผนที่นี้ เพราะช่วง 2→3 อยู่ไกล ได้สูงสุด 5

**reserve ย้ายที่ระหว่างออกแบบ:** ร่างแรกวางเป็นวงรอบทางออก แต่แต่ละช่องยิงถึงทางแค่ 3–6 ช่อง (ทางช่วงท้ายเข้าทางออกแนวทแยงแล้วจบ) จึงย้ายมาที่ x=16 ข้างช่องทางของ cp5 ที่ครีปผ่านสองรอบ ได้ 24–47 ช่อง

**สิ่งที่ได้เรียนรู้**
- **แทรกกำแพง hub กลางเกมทำให้แย่ลง**: ก้นหอยโตช้าลง และไฟที่ยิงถึงเส้นทางบินตอนด่าน 20 ต่ำลง (spiral2 ส่วนใหญ่ 10–16k)
- **ไฟบนเส้นทางบินคือตัวตัดสินที่ด่าน 20**: เกมเดียวของ spiral2-center ที่ไปถึงด่าน 28 (seed 2) มีไฟบนเส้นทางบินตอนด่าน 20 สูงถึง 251k และทางผ่าน hub 8 รอบ (หินจากเจมนอกแปลนทำให้ทางวนกลับเข้า hub เพิ่ม)
- **`reserveRespect` ไม่มีผล** เพราะบอทลงตามแปลน 100% อยู่แล้ว ไม่เคยวางทับ hub หรือ reserve
- **air focus ผ่านค่าน้ำหนักที่มีอยู่แทบไม่เปลี่ยนการตัดสินใจ**: โบนัสแปลน (สูงสุด +100) กลบ `airExposure` และเจม 87.5% ยิงอากาศได้อยู่แล้ว `airValue` จึงไม่ค่อยเปลี่ยนลำดับการเลือก ต้องใส่แนวยิงอากาศไว้ในตัวแปลน หรือเพิ่มค่าน้ำหนักที่ดูว่าเวฟถัดไปเป็นเวฟบินหรือไม่
- **ที่ weight 5 บอทไม่ยอมสร้างกำแพงที่อยู่ห่างทางเดิน** (ด่าน 7–10 ลงตามแปลน 0%) เพราะช่องไกลได้คะแนน exposure ต่ำ ต้องใช้ weight 10 ขึ้นไป
