# สรุป commit `5df1233` — Show what each gem can make while choosing

- **Branch:** `main` (ต่อจาก `6232530` หลัง fast-forward `ai-sim` เข้า `main`)
- **ประเภท:** quality of life ฝั่ง UI ไม่เปลี่ยนกฎเกม

## ที่มา

ช่วงเลือกเจม ผู้เล่นต้องคลิกเจมทีละเม็ดถึงจะรู้ว่าเม็ดไหนทำ special ได้ และตาราง Info ไม่แยกระหว่างเจมเก่าที่ keep ไว้ กับเจมรอบนี้ที่จะกลายเป็นหินถ้าไม่ใช้

ก่อนทำได้ตรวจกฎกับ JASS ของแมพ (BK's Gem TD v7.9) แล้ว:
- Downgrade (`A02G`) โผล่หลัง Keep (`A009`) เท่านั้น ตอนนั้นเจมอื่นเป็นหินไปแล้ว จึง combine ต่อไม่ได้ (ตรงกับเกมเรา)
- Combine Special ใช้เจมจากรอบก่อนได้ (tooltip `A03A`) แต่ต้องกดจากเจมรอบนี้ (ปุ่ม `A00R` มีเฉพาะเจมใหม่)
- Upgrade เป็นการอัปตึกปกติของ WC3 ทำได้ทันทีหลัง combine หรือ special ถ้ามีทอง

## 1. ส่วน "Specials with this gem" ในหน้าเจมที่เลือก

- แสดงทุกสูตรที่ใช้เจมนี้ พร้อมจำนวน เช่น `2/3`
- สูตรที่ทำได้ตอนนี้ขึ้นก่อน มี ★ และกรอบทอง
- แสดงทุกเฟส ระหว่างเวฟก็กดดูเจมเก่าได้ว่ายังขาดอะไร

## 2. แยก 3 สี (หน้าเลือกเจม และ Info > Special recipes)

- เขียว = เจมเก่าที่ keep ไว้แล้ว
- ทอง = วางในรอบนี้ ถ้าไม่ใช้จะเป็นหิน
- จาง = ยังไม่มี

**แก้บั๊กเดิม:** ตาราง Info เคยขึ้นว่า "พร้อม" ถ้ามีวัตถุดิบครบแม้เป็นเจมเก่าทั้งหมด ซึ่งจริง ๆ ทำไม่ได้ ตอนนี้ต้องมีเจมรอบนี้อย่างน้อย 1 เม็ด

ทุกจุดใช้ `Game.recipeStatus(recipe, focus)` ตัวเดียว (อ่านสถานะอย่างเดียว) ตัวเลขจึงตรงกับปุ่ม Special เสมอ

## 3. ป้ายลอยเหนือเจมบนบอร์ด (เฉพาะช่วงเลือกเจม)

- **Special:** ป้ายใหญ่ เช่น `★ STAR RUBY` ขอบทอง เรืองแสง ลอยขึ้นลง โผล่ครั้งแรกเด้งขยายพร้อมประกาย
  - ขึ้นป้ายเม็ดเดียวต่อสูตร ถ้าเลือกเจมที่เป็นวัตถุดิบอยู่ป้ายจะอยู่บนเจมนั้น ถ้าไม่ได้เลือกจะอยู่บนเม็ดที่วางล่าสุด
  - เม็ดเดียวทำได้หลายสูตร ต่อท้าย `+1`
- **Combine:** ป้ายเล็กกว่าและจางกว่า เช่น `2× → Flawless Ruby` ไม่ขึ้นถ้าเจมกลุ่มนั้นมีป้าย special แล้ว
- เจมแถวบนสุดห้อยป้ายไว้ใต้เจม ป้ายไม่หลุดขอบจอ
- คลิกหรือแตะป้าย = เลือกเจมนั้น
