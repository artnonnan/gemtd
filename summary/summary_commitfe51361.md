## 1. ป้ายสูตร slate บนบอร์ด

- ช่วงเลือกเจม ถ้าวางเจม Normal และเจม Flawed ที่เป็นคู่ของมันในรอบเดียวกัน จะมีป้ายสีฟ้าอมเขียว เช่น `◆ HOLD SLATE` เหนือเจม Normal (ใช้สีเดียวกับปุ่ม Create slate)
- เรืองแสงและเด้งขยายตอนโผล่ คลิกป้าย = เลือกเจมนั้น
- เจมเม็ดเดียวมีป้ายเดียว: special ขึ้นก่อน แล้วต่อท้าย `+N`
- ป้าย combine จะไม่ขึ้นถ้าเจมกลุ่มนั้นมีป้าย special หรือ slate แล้ว

## 2. ไฮไลท์ช่องวัตถุดิบบนบอร์ด

- ทำงานตอนชี้เมาส์ (มือถือ: แตะ) ที่แถวสูตรใน "Specials with this gem" หรือปุ่ม Special / Create slate / Combine
- สีของช่อง: ขาว = เจมที่เลือก ซึ่งจะกลายเป็นผลลัพธ์, เขียว = เจมเก่า, ทอง = เจมรอบนี้
- มีเส้นประวิ่งจากวัตถุดิบแต่ละเม็ดเข้าหาเจมที่เลือก
- บนคอม ไฟดับเมื่อเมาส์ออกจากแผงด้านล่าง บนมือถือ ไฟค้างจนแตะที่อื่นหรือเปลี่ยนเจม
- ตาราง Info ไม่มีไฮไลท์ เพราะหน้า Info บังบอร์ดทั้งหมด

## 3. ตัวเลขตรงกับของที่ถูกใช้จริง

- ถ้าเจมที่เลือกทำสูตรได้ตอนนี้ `recipeStatus()` จะแสดงเจมที่ Special จะใช้จริงทุกเม็ด (เกมใช้เจมรอบนี้ก่อนเจมเก่า) เช่น มีทั้ง Ruby เก่าและ Ruby รอบนี้ ไฮไลท์จะชี้ Ruby รอบนี้
- เพิ่ม `combineParts()` และ `slatePartner()` ใน `game.ts` ให้ทั้งการกระทำจริงและไฮไลท์ใช้ฟังก์ชันเดียวกัน
